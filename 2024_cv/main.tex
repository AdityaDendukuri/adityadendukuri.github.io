% Research Interests Section
\section*{Research Interests}
\noindent
My research is in numerical linear algebra and scientific computing, including sparse and structured
direct solvers, factorization reuse, Krylov methods and matrix functions, and randomized preconditioners,
with applications to the
simulation of and inference for large Markov chains and stochastic reaction networks. I develop these
methods as both analysis and open-source C++ and Julia software.

% Software Section
\section*{Software}
\begin{itemize}
    \item \textbf{numerics} -- C++20 numerical linear algebra library, developed solely by me, with dense,
          banded and sparse factorizations, Krylov solvers, matrix exponentials, Woodbury factorization
          reuse and mixed-precision LU. It has optional BLAS, LAPACK, OpenMP, SuiteSparse and FFTW back
          ends, hand-written CUDA kernels, C++20 concepts for operator properties, and Google Test and
          Google Benchmark suites. \href{https://adityadendukuri.github.io/numerics/}{Documentation},
          \href{https://github.com/AdityaDendukuri/numerics}{GitHub}.
    \item \textbf{markovkit} -- C++20 library for continuous-time Markov chains with adaptive and Krylov
          finite state projection, stochastic simulation, multigrid-preconditioned reaction-diffusion solvers,
          and subnetwork elimination.
          \href{https://adityadendukuri.github.io/numerics/markovkit/}{Documentation},
          \href{https://github.com/AdityaDendukuri/markovkit}{GitHub}.
    \item \textbf{AdjointKrylovGradients} -- Julia implementation and reproducibility code for the adjoint
          Krylov gradient paper. \href{https://github.com/AdityaDendukuri/AdjointKrylovGradients}{GitHub}.
    \item \textbf{approxchol} -- Header-only C++20 randomized approximate Cholesky for graph Laplacians,
          under 200 lines. \href{https://github.com/AdityaDendukuri/approxchol}{GitHub}.
\end{itemize}
